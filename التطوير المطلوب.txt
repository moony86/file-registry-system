FSYS v0.7.3 – Immersive Viewing Experience / Cinema Mode

الهدف:
تحسين تجربة المشاهدة في FSYS وتحويل التشغيل من مجرد video داخل Modal إلى تجربة Home Theater حقيقية.

لا تضف:
- AI
- Recommendations
- Watch History
- Continue Watching
- User Accounts
- Comments
- Chat
- Scraping
- TMDB / Anilist
- تغيير Streaming Backend
- تغيير Subtitle Backend
- تغيير Upload/Delete/Restore

المطلوب فقط:
واجهة مشاهدة مستقلة ومريحة للمستخدم.

==================================================
السياق
==================================================

FSYS حالياً يدعم:
- Upload
- Media Library
- Streaming
- Subtitles
- Thumbnails
- ffprobe metadata
- Delete/Restore
- File Inspector

المشكلة:
التشغيل الحالي يعمل، لكنه لا يعطي تجربة مشاهدة مريحة.
المطلوب إنشاء صفحة مشاهدة مخصصة.

==================================================
1) Watch Page
==================================================

أضف صفحة جديدة:

GET /watch/<file_id>

أو route مناسب داخل Master.

هذه الصفحة ليست Dashboard.

يجب أن تكون:
- Dark
- Clean
- Fullscreen-friendly
- بدون جداول
- بدون أدوات إدارة

عند فتحها:
- تجلب بيانات الملف
- تجلب media metadata
- تجلب subtitles
- تبني stream URL من node
- تعرض video player

==================================================
2) Cinema Mode UI
==================================================

التصميم:

- خلفية سوداء أو قريبة من الأسود.
- الفيديو في الوسط.
- معلومات بسيطة فوق أو تحت الفيديو.
- لا تعرض hashes أو paths أو node info.
- زر Back to Library.
- زر Back to Dashboard اختياري صغير.

إذا يوجد thumbnail:
استخدمه كخلفية ambient:
- blurred
- dark overlay
- brightness منخفض

إذا لا يوجد thumbnail:
خلفية سوداء عادية.

==================================================
3) Video Info
==================================================

اعرض فوق أو أسفل الفيديو:

- Title
- Collection title إن وجد
- Season/Episode إن وجد
- Duration إن وجد
- Resolution إن وجد
- Codec بشكل خفيف إن وجد

مثال:

Yofukashi no Uta
Season 1 • Episode 3
1080p • 23m

لا تعرض تفاصيل تقنية كثيرة.

==================================================
4) Player
==================================================

استخدم stream endpoint الحالي.
لا تغير backend.

يجب أن يدعم:
- subtitles الحالية
- controls
- fullscreen
- playback speed
- volume persistence

عند تحميل الصفحة:
- GET /api/files/<file_id>
- GET /api/media/files/<file_id>
- GET /api/media/files/<file_id>/subtitles
- GET /api/files/<file_id>/location لبناء stream URL إن كان مطلوباً

ثم:

video.src = http://node-host:node-port/api/files/<file_id>/stream

==================================================
5) Subtitles
==================================================

إذا توجد ترجمة active ومدعومة:
أضف <track> داخل video.

لكل subtitle:
src = /api/media/subtitles/<subtitle_id>/file
label = label أو language
srclang = language code إن أمكن
default إذا is_default = true

أضف خيار بسيط لعرض اللغات:
- Arabic
- English
- Off

إذا HTML5 controls كافية، لا تبالغ.

==================================================
6) Keyboard Shortcuts
==================================================

أضف shortcuts:

Space:
Play/Pause

ArrowRight:
+10 seconds

ArrowLeft:
-10 seconds

F:
Fullscreen

M:
Mute/Unmute

Escape:
إذا fullscreen اخرج منه

لا تجعل الاختصارات تعمل عندما المستخدم يكتب داخل input.

==================================================
7) Playback Settings LocalStorage
==================================================

احفظ محلياً:

- volume
- muted
- playbackRate
- selectedSubtitle إن أمكن

LocalStorage keys تكون مثل:

fsys.player.volume
fsys.player.muted
fsys.player.rate
fsys.player.subtitle

لا تحفظ watch position الآن.
هذا مؤجل لـ Continue Watching.

==================================================
8) Playback Speed
==================================================

أضف selector بسيط:

0.5x
1x
1.25x
1.5x
2x

عند التغيير:
- video.playbackRate = value
- احفظها في LocalStorage

==================================================
9) Next / Previous Episode
==================================================

إذا الملف الحالي جزء من media_item داخل collection:

اعثر على:
- previous episode
- next episode

المنطق:
نفس collection_id
نفس season_number
episode_number - 1
episode_number + 1

إذا لا توجد API حالية:
أضف endpoint صغير في master-node/routes/media.py:

GET /api/media/files/<file_id>/neighbors

يرجع:

{
  "previous": {
    "file_id": "...",
    "title": "...",
    "episode_number": 1
  },
  "next": {
    "file_id": "...",
    "title": "...",
    "episode_number": 3
  }
}

إذا الملف movie أو clip:
previous/next = null

في Watch Page:
أظهر:
← Previous Episode
Next Episode →

==================================================
10) End-of-Episode Prompt
==================================================

اختياري إذا سهل:

عندما يصل الفيديو إلى آخر 30 ثانية وكان next موجود:

أظهر:
Next Episode

زر:
Play Next

لا تضف autoplay إلزامي.
لا تعمل autoplay countdown معقد.

إذا صعب:
أجله واذكر أنه مؤجل.

==================================================
11) Navigation
==================================================

زر واضح:

Back to Library

يحاول الرجوع إلى:
- collection page إن كانت موجودة
- أو /anime
- أو /
- أو history.back()

لا تكسر إذا لا يوجد source.

==================================================
12) Viewer Integration
==================================================

أي زر Play في Viewer أو Media Library يجب أن يفتح:

/watch/<file_id>

بدل modal القديم، أو يمكن ترك modal في Dashboard فقط.

المطلوب:
- Viewer user experience تستخدم watch page.
- Admin Dashboard يمكن أن يبقى يستخدم modal أو watch page، اختر الأبسط.

==================================================
13) Mobile
==================================================

اجعل الصفحة responsive:

- الفيديو يأخذ العرض الكامل تقريباً.
- الأزرار تحت الفيديو.
- النصوص لا تزاحم الفيديو.

==================================================
14) ملفات متوقعة للتعديل
==================================================

Master:
- master-node/app.py أو routes/pages.py إن وجدت
- master-node/templates/watch.html جديد
- master-node/static/js/watch.js جديد
- master-node/static/css/watch.css إن كان المشروع يستخدم CSS منفصل
- master-node/routes/media.py لإضافة neighbors endpoint إن احتجت
- master-node/static/js/viewer.js لتغيير Play links إلى /watch/<file_id>
- master-node/static/js/dashboard.js فقط إذا لازم

لا تعدل Storage Node.

==================================================
15) اختبارات القبول
==================================================

اختبر:

1. فتح:
/watch/<file_id>

2. الفيديو يشتغل.

3. الخلفية مظلمة ومريحة.

4. subtitle تظهر إذا كانت موجودة.

5. Space يشغل/يوقف.

6. ArrowRight/ArrowLeft تقدم وترجع 10 ثواني.

7. F fullscreen.

8. M mute.

9. تغيير السرعة يبقى بعد refresh.

10. إذا الحلقة لها next:
زر Next Episode يعمل.

11. إذا الحلقة لها previous:
زر Previous Episode يعمل.

12. Play من Viewer يفتح watch page.

13. Play لا ينكسر في Dashboard.

==================================================
16) ممنوع
==================================================

لا تضف:
- Continue Watching
- Watch progress
- Database tracking للمشاهدة
- Users
- Profiles
- Recommendations
- External metadata
- Player library خارجية مثل video.js حالياً

استخدم HTML5 video.
